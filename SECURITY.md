# Security Policy

## Supported Versions

Security updates are actively maintained for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within GotifyWin, please report it responsibly:

* **Do not** disclose vulnerabilities in public GitHub issues, discussions, or pull requests.
* Submit a report via **[GitHub Private Vulnerability Reporting](https://github.com/roscocheeta/gotify-win-client/security/advisories/new)** on the repository.

Please provide:
1. A description of the vulnerability and its potential impact.
2. Steps or proof-of-concept to reproduce the behavior.
3. Suggested remediations, if available.

### Response Timeline
* Acknowledgement within **48–72 hours**.
* Status updates as the fix is developed and tested.
* Public disclosure coordinated after a patched release is published.
